# 工单：分阶段性能采样

| 字段 | 内容 |
| --- | --- |
| 任务名称 | 规则与表现分阶段性能采样 |
| 所属模块 | Core Rules / Presentation / PerformanceTests |
| 输入数据 | 固定 seed 202603、9×9 棋盘、固定合法交换、FIFO 表现事件 |
| 实现内容 | 在 `ResolveResult` 附加旁路性能轨迹，记录匹配、特殊规则、消除、下落补充、洗牌、总逻辑和表现播放耗时 |
| 涉及文件 | `Core/Diagnostics/TurnPerformanceTrace.cs`、`Match3Core.cs`、`MvpRulePipeline.cs`、`EffectPlayer.cs`、`Match3DemoController.cs`、PerformanceTests 与交付文档 |
| 验收标准 | 固定回放 100 次一致；平均总逻辑耗时小于 50ms；有效交换包含匹配、消除和下落补充样本；表现层可回填播放耗时；采样不进入回放摘要 |
| 测试场景 | 预热后连续执行固定合法交换 100 次，累计并输出各阶段平均耗时 |
| 人工校验 | 比较采样前后最终棋盘和分数；检查 `[Performance]` 日志字段；运行 Core、Architecture、Flow、Performance 和 UnityCompileTests |
| 已知风险 | 当前环境无法运行 Unity PlayMode，真实协程等待和渲染耗时只能在 Unity 2022.3 LTS/Windows Standalone 中复核 |

特殊糖果属于 EXT 且 MVP 默认关闭，因此当前 `specialMs` 与 `SpecialCount` 保持 0；这不是缺失采样，而是明确记录该阶段未执行。
