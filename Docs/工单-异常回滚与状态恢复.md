# 工单：异常回滚与状态恢复

| 字段 | 内容 |
| --- | --- |
| 任务名称 | TurnResolver 规则异常回滚与输入恢复 |
| 所属模块 | Architecture / Flow |
| 输入数据 | 注入抛异常规则管线、固定棋盘和随机流 |
| 实现内容 | 规则执行前捕获 `BoardState`；规则或事件入队异常时恢复棋盘、清空事件、记录 Rule 类型 `ErrorSnapshot`，返回无效结果；输入层恢复 Idle |
| 验收标准 | 棋盘、步数、随机游标、事件队列和回放无副作用；错误快照可导出；异常命令不增加回合号 |
| 测试场景 | 交换规则抛异常并先修改步数/随机流；检查恢复与诊断字段 |
| 人工校验 | Unity 中注入故障或构造事件上限异常，确认错误日志、快照路径和棋盘重新可操作 |
| 已知风险 | 当前无 Unity 编辑器，真实异常触发与 UI 恢复仍需 PlayMode 验收 |
