# 工单：输入协调与终态锁

| 字段 | 内容 |
| --- | --- |
| 任务名称 | 提取纯 C# InputController 并验证终态输入锁 |
| 所属模块 | Flow / Presentation / ArchitectureTests |
| 输入数据 | 棋盘命中坐标、固定有效交换、Win/Lose 状态下各 20 次点击 |
| 实现内容 | 将选择、改选、取消、交换/道具提交、回合编号和输入锁判断从 MonoBehaviour 提取到 Flow；表现 Controller 只转换鼠标命中与显示结果 |
| 涉及文件 | `Flow/InputController.cs`、`Match3DemoController.cs`、ArchitectureTests、架构与启动说明 |
| 验收标准 | 输入命令只通过 TurnResolver；有效交换进入 Animating；Win/Lose 点击全部返回 Locked；棋盘、步数、随机游标、队列、回放和回合编号无变化 |
| 测试场景 | 固定棋盘选择 `(1,3)` 后点击 `(1,4)`；Win 与 Lose 各循环点击 20 次 |
| 人工校验 | 核对 Controller 不直接调用 `SubmitSwap`/`SubmitAreaTool`；运行全量独立测试和 Unity C# 离线编译 |
| 已知风险 | 当前无法执行 Unity PlayMode，真实鼠标事件与结果面板遮挡仍需 Unity 2022.3 LTS 中复核 |

该工单不改变交换、道具、目标或胜负规则。`InputController` 不依赖 UnityEngine，也不消费表现事件。
