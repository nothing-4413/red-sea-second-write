# 工单：错误快照导出

| 字段 | 内容 |
| --- | --- |
| 任务名称 | 版本化错误快照导出 |
| 所属模块 | Architecture / Presentation |
| 输入数据 | `ErrorSnapshot`、Unity 持久化数据根目录 |
| 实现内容 | 将错误类型、回合、状态、seed、随机游标、队列长度和棋盘快照导出为 schema v1 JSON；表现超时后自动落盘，失败时回退到错误日志 |
| 涉及文件 | `ErrorSnapshotExporter.cs`、`Match3DemoController.cs`、ArchitectureTests、启动与架构说明 |
| 验收标准 | JSON 可解析、字段完整、文本正确转义、UTF-8 无 BOM、同名不覆盖、导出失败不阻断状态恢复 |
| 测试场景 | 固定时间同一回合连续导出两次；消息包含引号与换行；根目录为空 |
| 人工校验 | 运行 ArchitectureTests，核对导出目录边界和 JSON 字段；运行 Unity C# 离线编译 |
| 已知风险 | 当前环境没有 Unity 2022.3 LTS，`Application.persistentDataPath` 的真机路径与 Console 日志仍需 PlayMode/Standalone 验收 |

本工单不修改 `BoardModel`、规则输出或回放一致性判定。文件系统写入位于 Architecture 诊断边界，Unity 表现层只提供持久化根目录并显示结果。
