# 工单：棋盘完整性校验

| 字段 | 内容 |
| --- | --- |
| 任务名称 | 命令边界棋盘完整性校验与异常恢复 |
| 所属模块 | Core / Architecture / Flow |
| 输入数据 | `BoardModel` 稳定状态、规则管线返回结果 |
| 实现文件 | `Core/Diagnostics/BoardIntegrityValidator.cs`、`Architecture/TurnResolver.cs`、`ArchitectureTests/Program.cs` |
| 校验内容 | 重复 `PieceId`、`Piece.LogicalPos` 与格子坐标不一致、障碍物耐久度小于 0、无障碍稳定格出现空格 |
| 主流程 | `TurnResolver` 在规则执行前校验输入；规则返回成功后再次校验；失败则抛出结构化诊断文本并复用 `BoardState` 回滚 |
| 异常处理 | `TurnResolver` 保存最近一次完整性通过的稳定快照；异常时优先恢复本次命令前快照，若其本身已损坏则回退到稳定快照；之后清空事件队列、保持回放不写入、`InputController` 返回无效结果并恢复 `Idle`，`LastError` 记录 `Rule` 类型快照 |
| 验收标准 | 健康棋盘通过；四类坏棋盘均能识别；棋盘、随机游标、事件、回放和回合号无副作用 |
| 自动测试 | Architecture 53 项通过，其中包含四类坏棋盘、回滚和恢复可操作状态测试；Core 18/18 通过 |
| 人工校验 | Unity 编辑器中注入坏状态或规则故障，确认 Console 错误、快照路径、棋盘视图同步和再次点击可操作 |
| 已知风险 | 完整性校验假设命令边界棋盘应填满可通行格；消除/下落的中间态只能在规则内部存在，不能被表现层或外部系统读取 |
