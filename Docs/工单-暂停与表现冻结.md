# 工单：暂停与表现冻结

| 字段 | 内容 |
| --- | --- |
| 任务名称 | 暂停/继续状态与表现等待计时冻结 |
| 所属模块 | Flow / Presentation |
| 输入数据 | Idle、Selecting、Resolving、Animating 等状态；暂停按钮命令 |
| 实现内容 | `TurnStateMachine` 保存暂停前状态；`InputController` 自动继承暂停输入锁；`EffectPlayer` 暂停协程等待和性能计时；终态禁止暂停 |
| 验收标准 | 暂停期间输入锁定；恢复后返回原状态；表现事件等待时间不推进；Win/Lose 不可暂停 |
| 测试场景 | Flow/Architecture 契约测试覆盖 Selecting、Resolving、Animating、Win、Lose |
| 人工校验 | Unity 2022.3 LTS 中启动 GameScene，点击暂停观察事件计时与 UI，继续后确认 FIFO 顺序和状态恢复 |
| 已知风险 | 当前无 Unity 编辑器，真实协程与 `Time.deltaTime` 冻结尚未完成 PlayMode 验收 |

该工单不改变规则结算、目标、分数或回放数据。
