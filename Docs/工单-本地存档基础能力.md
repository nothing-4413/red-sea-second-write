# 工单：本地存档基础能力

| 字段 | 内容 |
| --- | --- |
| 任务名称 | 稳定进度本地存档与异常回退 |
| 所属模块 | Architecture / Presentation |
| 输入数据 | 关卡 ID、配置版本、剩余步数、道具、分数、目标进度 |
| 实现内容 | `LocalSaveService` 输出 schema v1 JSON；稳定回合自动保存；启动时校验文件、版本和数值，失败回退默认进度 |
| 涉及文件 | `LocalSaveService.cs`、`Match3DemoController.cs`、ArchitectureTests、启动/架构/交付文档 |
| 验收标准 | 保存可读写；UTF-8 无 BOM；缺失、损坏、旧版本、错关卡、错配置版本和越界数据均回退；不保存动画、暂停、队列和临时棋盘 |
| 测试场景 | 临时目录往返读写、缺失字段、错关卡、负数越界 |
| 人工校验 | Unity 2022.3 LTS 中完成一回合后重启，核对 `Application.persistentDataPath/Saves` 文件和 UI 进度 |
| 已知风险 | 当前无 Unity 编辑器，真实持久化路径、重启生命周期和 Player 数据目录仍需 PlayMode/Standalone 验收 |
