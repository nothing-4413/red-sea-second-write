# 红海二笔二测交付说明

## 方向与范围

本交付沿用一测声明的“架构设计线”。实现技术为 Unity 2022.3 LTS / C#；规则层可脱离 Unity 独立编译和测试，表现层只负责输入、装配、绘制和事件消费。

MVP 已覆盖：普通三连、相邻交换、无效交换回滚、下落与补充、连锁结算、确定性 seed、障碍物、5×5 范围道具、无合法移动自动洗牌、目标/步数/胜负边界、回放元数据和 FIFO 事件队列。特殊糖果开关保留为 EXT，默认关闭。

## 新电脑启动

关卡配置资产为 Demo/UnityProject/Assets/Config/LevelConfig_001.asset，GameScene 已绑定该资产；Unity 层将其转换为纯 C# LevelConfig 后创建 BoardModel。

1. 安装 Unity 2022.3 LTS。
2. 打开 `Demo/UnityProject`。
3. 运行 `Assets/Scenes/GameScene.unity`；空场景会由 `DemoBootstrap` 自动装配 `BoardView` 和 `Match3DemoController`。
4. 点击相邻糖果进行交换；运行期间事件动画消费完成前输入锁定。
5. 开发构建中的“回放固定操作”入口使用固定 seed 和坐标输入；日志输出包含事件类型、回合编号和连锁深度。

独立规则验证：

```powershell
dotnet run --project Demo/CoreTests/CoreTests.csproj
dotnet run --project Demo/ArchitectureTests/ArchitectureTests.csproj
dotnet run --project Demo/FlowTests/FlowTests.csproj
```
